1. **输入用你真实的说法**，不要写成关键词。"冬天车里开暖风耗不耗电"这类句子才有语义层的价值，
   写成"新能源汽车 暖电"就退化成全文匹配能干的活。
2. **"期望命中的文档"给我到能唯一定位的程度**：文件全名，或库里的 `doc_id`，或"绝对路径也行"。
3. **"期望页码"不知道就留空**，留空的条目只算 Recall@10 的文档级命中，不参与"命中必须给页码"那条判据。
4. **最后一列你可以空着**（那一列是我来跑的：每条先跑一遍纯全文，看它本来能不能召回）。
   你写"这条我确信全文搜不到"的，请标出来 —— 那正是 **互补性 ≥ 4/20** 要用的样本。

### 我要跑的四条判据（D-035，全部可断言）
- **Recall@10 ≥ 18/20**；
- **互补性 ≥ 4/20**：全文召不回而语义召得回；
- **不回归**：混合检索（RRF，**D-038**）后这 20 条的 top-1 不得低于纯全文；
- **可定位**：每条语义命中必须带 `doc_id` + `page_no` + 原文片段，给不出页码的命中不显示。

四条里任何一条不达标，交付报告里语义搜索就写在**「已实现但未充分验证」或「部分实现」**栏，
**不许**因为"模型跑通了、界面有结果"而进第一栏。
