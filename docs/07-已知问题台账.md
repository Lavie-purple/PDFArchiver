## 附 · I3 的 `pip check` 原文

```
rapidocr-onnxruntime 1.4.4 requires onnxruntime, which is not installed.
```

**这一行是预期的，不要去"修"它。** 修它的办法是把纯 `onnxruntime` 装回来，而那正是
docs/00 2.2 里 `import onnxruntime` 段错误（exit 139）的成因。
