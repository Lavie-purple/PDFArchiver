三个读数值得单独说：

- **`27 passed` 不等于"检索层的全部"**。门禁跑的是 `tests/integration/test_search_service.py` 一个文件，
  判据里带 `passed >= 15` 的下限 —— 这条下限的作用是让"一个测试也没收集到"不能算绿。

## 四 · 未达清单（四项一起，因为它们同一个根因）

四项的共同形状：**仓储与界面各自都在，中间那根线没接**。这与 **ISSUES I55**（S3/S4 四处
"控件在场、链路不在场"）是同族，区别是 I55 的文案已经改成只报事实，而这四项连"报错了事实"都没有 ——
界面上它们**看起来是可用的功能**。

| 编号项 | 内容 | 需要线框确认吗 |

| **ISSUES I78** 甲 | 文档↔分类 / 标签的界面写路径，与批量打标签同批落地（多选 + 幂等 + 冲突断言） | **需要**（新控件） |

| 另账 | `reparent_category` / `merge_categories` / `merge_tags` 三个仓储方法在产品里零调用方（分类树不能挪父子、不能合并） | 归 I78 甲的同一批控件 |
