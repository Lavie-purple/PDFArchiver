# QUICKSTART —— 第一次拿到的十分钟

这一页只回答一个问题：**从零到"我能在里面搜到我自己的 PDF"要走哪几步**。
每一步的细节都在括号里指向对应的完整文档；本页不重复那些内容。

## 三步动线

**第 1 步 · 启动**
双击启动（源码运行按 [`INSTALL.md`](INSTALL.md) 的命令行步骤）。程序只会在
`你的用户目录\AppData\Local\PdfArchiver` 建一个空档案库，不改你任何文件；
想放别的盘，启动时用 `--data-dir` 指目录。启动后控制台黑窗口**最小化、别关**——
关掉它等于杀掉整个程序（原因见 [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md)）。

**第 2 步 · 登记要盯着的文件夹**
侧栏进「设置与状态」→ 下半区「监测目录」→ 点「**添加目录…**」，选中一个文件夹就登记好了。
之后扫描、抽正文、建索引**全自动**，关掉程序再打开也会接着跑。
（撤监测 ≠ 删你的文件，细节见 [`USAGE.md`](USAGE.md) 第四节。）

**第 3 步 · 等索引，然后验收**
进度看「设置与状态」上半区（库里多少份、索引跑到哪、有没有报错，全是现查的数字）。
**验收判据就一条**：侧栏进「文档库」，在顶部搜索框输入你某个 PDF 标题里的词，
能命中它 = 装好了。搜不到时先看上半区索引是否还在跑，再对照
[`TROUBLESHOOTING.md`](TROUBLESHOOTING.md)。

## 装好之后最常用的三件事

| 想做什么 | 去哪点 | 说明 |
| --- | --- | --- |
| 接着上次读的 PDF | 侧栏「**继续阅读**」 | 一键打开最近读的那份、落在上次那页；没读过会提示 |
| 扫描件变成可搜的文字 | 「文档库」选中 →「送去识别」 | 本地 OCR，有每日页数预算，细节见 [`OCR.md`](OCR.md) |
| 备份整个档案库 | 见 [`BACKUP-RESTORE.md`](BACKUP-RESTORE.md) | 备份 = 拷库文件 + 旁边的 `config\settings.json` |

## 出了问题

- 双击没反应 / 窗口消失：看 `数据目录\logs\crash.log`，拿原文对照
  [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md)。
- 想知道某个数字、某个按钮的完整行为：[`USAGE.md`](USAGE.md) 逐屏有表。
- 第一次运行 Windows 拦一下（程序无数字签名）是预期的，处理见故障排查。
