# NostalgiaFor Everything

**把你电脑上散落多年的 PDF，变成一座搜得到、读得了、理得清的本地档案库。**

合同、发票、报告、说明书、扫描件、旧资料 —— 它们通常有上千份，文件名起得随便，内容里那句话你记得见过，
却不知道自己点过多少次鼠标才找到。这个工具做的事只有一件：**把你的文档目录交给它一次，之后按内容找东西。**

程序完全跑在你自己这台电脑上。**不上传、不联网、不开账号**，所有东西存在一个文件夹里，删掉那个文件夹就等于彻底清除。

---

## 它会为你做四件事

### 1）认全 —— 扫一遍，就知道你有哪些 PDF

你告诉它"盯着这几个文件夹"，它会把里面（含子文件夹）所有 PDF 登记下来：文件名、多大、几页、哪年改的、
谁写的。之后文件夹里新增、删除、改名，它自己看得见，不用你重新扫。

### 2）读进去 —— 连扫描图片里的字也读

每一份 PDF 的正文都会被抽出来建索引。**扫描版**（打印出来拍照再拼成 PDF 的那种）里没有真文字，
它就在本机做一次离线文字识别（OCR），把图里的字认出来再进索引。识别有每日页数预算，跑满会自动停，
不会把你的电脑占着不放。

### 3）搜得到 —— 像用搜索引擎一样搜自己的电脑

输入关键词，结果会告诉你**命中在哪个文件的第几页**，点一下直接翻到那一页。可以按分类、标签、
文件所在目录、年份这些条件筛。在一台普通 Windows 10 机器上、一份 **1 万份文档 / 197 万页正文**的真实档案库里，
实测搜索响应 **P95 = 0.33 秒**（这个数字每次都能用项目自带的脚本重新量出来）。

### 4）理得清 —— 分类、标签、重复文件、备份

- **分类树 + 多标签**：一份文件可以同时属于好几个标签，树状分类随你整理。
- **智能集合**：常用的那组筛选条件存成一个入口，下次点一下就回来。
- **重复检测**：按内容找出"一模一样但存了好几份"的文件，告诉你浪费了多少空间。
- **备份与恢复**：一键把整个档案库快照成一个文件；换电脑时把那个文件夹拷走就行。
- **PDF 阅读**：不用离开程序就能看，翻页、跳页码，它记得你上次读到第几页。

## 现在能做到什么、还做不到什么（说清楚，不糊弄）

| | 状态 | 说明 |
| --- | --- | --- |
| 扫描、抽正文、建索引、全文搜索 | ✅ 能用 | 界面和后台都是通的 |
| 离线 OCR 扫描件 | ✅ 能用 | 在本机跑，有每日页数预算 |
| 分类 / 标签 / 智能集合 / 阅读 / 重复检测 / 备份恢复 | ✅ 能用 | |
| 登记"要盯着哪些文件夹" | ⚠️ 要做一次命令行操作 | 界面上那两个按钮今天不会真登记；[`docs/USAGE.md`](docs/USAGE.md) 第四节给了一段可以整段复制粘贴的脚本，登记之后扫描与建索引全自动 |
| 按规则自动移动 / 改名归档 | ⚠️ 只能预览 | 它能列出"打算怎么搬"，但**不会真动你的文件** —— 界面上没有执行入口 |
| 撤销一次归档 | ❌ 还没做 | |
| 语义搜索 / "AI 推荐分类" | ⚠️ 会明确告诉你它没有数据 | 功能在界面上，但目前档案库里还没有向量数据，点了会显示"暂无向量数据"，不会假装给了你答案 |
| 安装包 / 卸载器 / 开始菜单 | ❌ 没有 | 现在只有"把一个文件夹拷到机器上"这一种安装方式 |
| macOS / Linux / 手机端 | ❌ 不支持 | 只做过 Windows 10 / 11 |
| 云端同步、多人共用 | ❌ 不做 | 这是本地工具的边界，不是没来得及 |

> **一句话让你放心**：目前这个版本的界面**不会改动你磁盘上的任何文件**。
> 它只做索引、搜索、整理和记录。搬文件的能力代码已经写好并单独测过，只是还没接到界面上。

## 怎么开始用

1. **拿到程序**：这个项目现在**还不提供下载好的安装包**。如果你是从源码运行，
   按 [`docs/INSTALL.md`](docs/INSTALL.md) 走一遍（有 Windows 命令行步骤，复制粘贴即可）。
2. **第一次启动**：它只会在你机器上建一个空档案库，什么都不会改动。
   默认存放位置是 `你的用户目录\AppData\Local\PdfArchiver`，想放到别的盘，启动时指个目录就行。
3. **让它认识你的文件夹**：这一步今天还要用一次命令行（见上表 ⚠️ 那行）。登记完之后，
   剩下的扫描、抽正文、建索引全是自动的，关掉程序再打开也会接着跑。
4. **开始搜**：打开程序默认落在「文档库」这一屏，顶部搜索框就是入口。
5. **想知道它到底在你机器上做了什么**：看「设置与状态」这一屏 —— 版本、数据放在哪、库里有多少份文档、
   索引跑到百分之几、有没有报错，每一个数字都是当场从库里查出来的，不是写死的。

**找不到程序窗口 / 双击没反应？** 去看 `数据目录\logs\crash.log`，那里有完整原因，
对照 [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md) 逐条排。第一次运行 Windows 可能会拦一下
（程序没有数字签名），这是预期的，说明见故障排查。

## 你的数据在你手里

- 所有索引、正文、标签都存在**一个文件**里（`catalog.db`），没有第二份副本，也没有任何数据离开这台机器。
- 文字识别用的模型也在你本地，运行期间不联网。只有你主动要用语义搜索时，才需要自己下载一个本地模型。
- 备份 = 复制那个文件（连同旁边的 `config\settings.json` 一起拷才是完整一份 —— 程序里的备份按钮目前只拷库）。
- **换机器要注意**：档案库连同识别出来的文字一起拷过去都没问题，但库里记的是**旧机器上的文件路径**。
  新机器上路径对不上时，程序不会删掉记录，而是把它们标成"找不到"等你重新定位；
  第一次启动还要重新登记一次要盯着的文件夹。完整步骤见 [`docs/BACKUP-RESTORE.md`](docs/BACKUP-RESTORE.md) 第七节。
- 卸载 = 删掉数据目录 + 删掉程序目录。没有注册表残留，没有后台服务。
